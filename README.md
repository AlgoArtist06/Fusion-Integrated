# Assignment 6 evidence: 24BCS041 and 24BCS147

This branch holds the AI interaction records for the ELM pilot.
It holds no application code.
The code is on the PR branches listed below.

## Setup used for every run

- Hardware: MacBook Air M2 (8 GB unified memory), macOS 27.0.
- Runtime: llama.cpp b11560 (Metal), `llama-server`, one model at a time.
- Server flags: `-c 32768 -ngl 999 -fa on -ctk q8_0 -ctv q8_0 --cache-ram 0 -ctxcp 8` (FrogNano also `--spec-type draft-mtp`).
- Coding agent: Pi coding agent, non-interactive (`pi -p --mode json`), sampling temperature 0.6, top-p 0.95, top-k 20.
- Base: Fusion-Integrated `main` at 02b01fe, a fresh clone for each implementation.

Each folder contains:

- `prompts.md`: the exact system prompt and user prompt sent, extracted from the session file.
- `pi-session.jsonl`: the full Pi session (every message, tool call and tool result).
- `events.jsonl`: Pi's JSON event stream.
- `server.log`: the llama.cpp server log, with prompt and generation speeds.
- the code diff the model produced, and the grading or run summary.

`phase1-impl1-frognano/harness/` holds the benchmark script that drove and graded the FrogNano run, its appended repository guide, and the decision log.
`phase1-impl2-qwen35/run_qwen.sh` drove the Qwen run, including its prompt.
